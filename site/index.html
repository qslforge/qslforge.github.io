QSLforge is de tool waarmee ON3VZ QSL-kaarten maakt en verstuurt voor portable activaties (POTA, WWFF/ONFF, SOTA, BOTA, COTA).

QSLforge is the tool ON3VZ uses to create and send QSL cards for portable activations.
