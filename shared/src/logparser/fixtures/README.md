# Test fixtures

Only **fictitious** logs belong here. This repository is public, and call signs and e-mail addresses are personal data under the GDPR.

Rules:

- Use call signs that cannot belong to a real station, for example `ON0TEST`, `ON9ZZZ`, `DL0XXX`, `G0TEST`.
- Never copy QSOs from a real log, not even with altered times.
- No e-mail addresses other than `@example.com`.
- File names describe the case, for example `polo-pota-basic.adi`, `wsjtx-ft8-with-dupes.adi`, `cabrillo-3.0-minimal.cbr`.

The parser itself is built in phase 1.
